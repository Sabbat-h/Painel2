Painel do Desenvolvedor — Entendendo o JSON

Nesta seção, explicamos como o sistema utiliza JavaScript e JSON para consultar informações de endereços por meio da API ViaCEP.

1. O que é JSON?

JSON (JavaScript Object Notation) é um formato de texto utilizado para organizar e trocar informações entre sistemas. Os dados são estruturados em pares de chave e valor, facilitando a leitura e o processamento pelo JavaScript.

Exemplo de resposta JSON do ViaCEP:

{
"cep": "01001-000",
"logradouro": "Praça da Sé",
"bairro": "Sé",
"localidade": "São Paulo",
"uf": "SP"
}

Nesse exemplo, "localidade" é uma chave e "São Paulo" é seu valor.

2. Como a requisição funciona no navegador?

O JavaScript utiliza a função fetch() para solicitar informações de uma API pela internet. No nosso projeto, o fetch() consulta o ViaCEP utilizando o CEP informado pelo usuário. Essa requisição acontece de maneira assíncrona, permitindo que a página continue funcionando sem precisar ser recarregada.

Exemplo:

fetch("https://viacep.com.br/ws/01001000/json/")
.then(resposta => resposta.json())
.then(dados => {
    console.log(dados);
});

O fetch() envia a solicitação ao ViaCEP e recebe uma resposta com as informações correspondentes ao CEP pesquisado.

3. Como o JavaScript utiliza a resposta?

Após receber a resposta da API, o JavaScript utiliza o método .json() para interpretar o conteúdo JSON e transformá-lo em um objeto JavaScript. Dessa forma, podemos acessar os dados utilizando suas respectivas chaves.

Exemplo:

fetch("https://viacep.com.br/ws/01001000/json/")
.then(resposta => resposta.json())
.then(dados => {

    // Acessa a cidade retornada pela API
    const cidade = dados.localidade;

    // Acessa o estado retornado pela API
    const estado = dados.uf;

    // Exibe a cidade e o estado
    console.log(cidade + " / " + estado);

});

No sistema da clínica, essas informações são utilizadas para preencher automaticamente o campo Cidade / UF do formulário de cadastro.

Resumo do funcionamento

1. O usuário digita o CEP no formulário.

2. O fetch() consulta a API ViaCEP.

3. A API retorna os dados no formato JSON.

4. O método .json() transforma a resposta em um objeto JavaScript.

5. O JavaScript utiliza os dados para preencher automaticamente Cidade / UF.
